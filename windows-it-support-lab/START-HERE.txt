START HERE — Windows IT Support Project

1. Extract this ZIP on your Windows computer.
2. Read docs/commands.md and run commands ONE AT A TIME in Windows PowerShell.
3. Complete docs/support-ticket.md using your real results.
4. Save only redacted screenshots in evidence/.
5. Update README.md; remove the IN PROGRESS label after you've verified your work.
6. Publish README.md, docs/, scripts/, evidence/ and .gitignore to a PUBLIC GitHub repository named windows-it-support-lab.
7. Do not upload private-results/, personal information, or raw diagnostic reports.

The script scripts/diagnose.ps1 is OPTIONAL. The manual procedure works even when scripts are blocked by Windows execution policy.
